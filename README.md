## Customize later

- **Photos:** replace the gradient `.m1`–`.m6` backgrounds with real images (`background-image: url(...)`).
- **RSVP:** responses save in the browser via `localStorage` key `nn-wedding-rsvp` (demo only).
- **Music:** soft ambient tones generated in-browser (no audio file required).
